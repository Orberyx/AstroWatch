## 📁 Organização do Projeto

| Diretório | Finalidade |
|---|---|
| `src/` | Código-fonte da aplicação Java |
| `resources/` | Ícones, imagens e demais recursos utilizados pela aplicação |
| `database/` | Modelagem e scripts do banco de dados |
| `docs/` | Documentação produzida pela equipe |
| `support/` | Materiais externos utilizados como apoio ao desenvolvimento |

## 🗄️ Banco de Dados

A pasta `database/` centraliza os arquivos relacionados à modelagem e estrutura do banco de dados.

```text
database/
├── DER/
├── DL/
└── scripts/
```

- `DER/` — Diagrama Entidade-Relacionamento.
- `DL/` — Diagrama Lógico.
- `scripts/` — scripts SQL de criação, alteração e inserção de dados.

## 📚 Documentação

A pasta `docs/` reúne a documentação produzida pela equipe durante o planejamento, desenvolvimento e apresentação do projeto.

```text
docs/
├── uml/
├── ui-ux/
│ ├── wireframes/
│ ├── mockups/
│ └── prototypes/
├── diagrams/
└── presentations/
```

- `uml/` — diagramas UML.
- `ui-ux/wireframes/` — esboços das interfaces.
- `ui-ux/mockups/` — representações visuais das interfaces.
- `ui-ux/prototypes/` — protótipos das telas e navegação.
- `diagrams/` — outros diagramas e representações visuais do projeto.
- `presentations/` — slides e materiais utilizados nas apresentações.

## 🎨 Recursos

A pasta `resources/` armazena recursos utilizados diretamente pela aplicação.

```text
resources/
├── icons/
└── images/
```

- `icons/` — ícones utilizados na interface.
- `images/` — imagens utilizadas pela aplicação.

## 🧰 Materiais de Apoio

A pasta `support/` reúne materiais externos utilizados pela equipe como apoio durante o desenvolvimento.

```text
support/
├── documents/
├── videos/
├── tutorials/
└── references/
```

- `documents/` — documentos e materiais de consulta.
- `videos/` — vídeos e videoaulas utilizados pela equipe.
- `tutorials/` — tutoriais e guias utilizados durante o desenvolvimento.
- `references/` — documentações, artigos, ferramentas e outras referências técnicas.

> **Observação:** pastas relacionadas a recursos ainda não utilizados pelo projeto podem ser omitidas até que sejam necessárias.
